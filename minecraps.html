Minecraps

Our family Minecraft world, running on the Flying Cocker server so everyone can build together from their own console, phone, tablet or Windows 10/11 device. Add the server once using the details below, then just tap Join Server whenever you want to play.

Edition

Bedrock is the version on Xbox, PlayStation, Nintendo Switch, iPhone/iPad, Android, and the “Minecraft” app on Windows 10/11. (Java Edition on PC can’t join this one.)

How to join

  1. Open Minecraft and press Play.
  2. Go to the Servers tab.
  3. Scroll to the bottom and choose Add Server.
  4. Server Name: Flying Cocker (anything you like).
  5. Server Address: mc.theflyingcocker.co.uk
  6. Port: 19132
  7. Press Save, then tap the server to Join Server.

First time only: you need to be added to the allow-list before you can get in. Tell the grown-up who runs the server your exact in-game gamertag and they’ll add you.

House rules

  • Be kind — no breaking or taking other people’s builds without asking.
  • No griefing and no bad language in chat.
  • Share the fun — help each other build and explore.
  • If something breaks or someone’s being unkind, tell a grown-up.
